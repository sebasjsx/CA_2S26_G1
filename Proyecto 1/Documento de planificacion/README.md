# Documento de Planificación – Capacitación sobre APIs REST

## 1. Tema elegido

El tema seleccionado para la capacitación es **APIs REST**.

Este tema fue elegido porque permite explicar de manera clara y práctica cómo se comunican las aplicaciones mediante peticiones y respuestas, incluyendo la relación entre frontend, backend y base de datos.

Durante la planificación se consideraron también los temas **Ética del hacking** y **Cifrado de información**, pero finalmente se seleccionó APIs REST por permitir combinar explicación teórica con ejemplos y una actividad práctica.

---

## 2. Lista preliminar de subtemas

| No. | Subtema | Contenido |
|---|---|---|
| 1 | Introducción a las API REST | Definición de API, significado de REST, propósito y ejemplos cotidianos. |
| 2 | Arquitectura y funcionamiento | Cliente, servidor, API, frontend, backend, base de datos, endpoints, peticiones y respuestas. |
| 3 | Métodos HTTP | GET, POST, PUT, PATCH y DELETE. |
| 4 | Intercambio de información | URL, parámetros, headers, body, JSON y códigos HTTP. |
| 5 | Seguridad en API REST | HTTPS, autenticación, autorización, tokens, roles y validación. |
| 6 | Ejercicio práctico | Aplicación de los conceptos vistos mediante un proyecto de Gestor de Tareas |

## 3. Estructura de la capacitación

La capacitación se desarrollará de forma progresiva, iniciando con conceptos básicos de las APIs REST y finalizando con una aplicación práctica de los conocimientos adquiridos.

### 3.1 Introducción y rompehielos (Por: Marina Mejía)

Se realizará una breve presentación del tema y una actividad rompehielos para conocer los conocimientos previos de la audiencia. Se utilizarán ejemplos de aplicaciones de uso cotidiano para introducir el concepto de API.

### 3.2 Introducción a las APIs REST (Por: Esther García)

Se explicará qué es una API, qué significa REST, cuál es su propósito y cómo se utilizan las APIs en aplicaciones modernas.

### 3.3 Arquitectura y funcionamiento (Por: Pablo Colop)

Se explicará la relación entre cliente, servidor, frontend, backend, API y base de datos, así como el funcionamiento de los endpoints, peticiones y respuestas.

### 3.4 Métodos HTTP (Walter Martinez)

Se explicarán los principales métodos HTTP:

- GET
- POST
- PUT
- PATCH
- DELETE

Se utilizarán ejemplos sencillos para mostrar la función de cada método.

### 3.5 Intercambio de información (por: Marina Mejía)

Se explicarán los principales elementos que intervienen en una petición y respuesta:

- URL
- Parámetros
- Headers
- Body
- JSON
- Códigos de estado HTTP

### 3.6 Seguridad en APIs REST (por: Chung Kim)

Se abordarán conceptos básicos relacionados con:

- HTTPS
- Autenticación
- Autorización
- Tokens
- Roles
- Validación

### 3.7 Ejercicio práctico (por: Denis Abad)

Para reforzar la teoría se utilizará una aplicación de **gestión de tareas**, desarrollada con **React** en el frontend, **Node.js y Express** en el backend y **MongoDB** como base de datos.

Mediante esta aplicación se ejemplificará de forma práctica el uso de los métodos HTTP al consultar, crear, modificar y eliminar tareas.

### 3.8 Validación y cierre (Kahoot: hecho por Chung Kim)

Al finalizar se realizará un cuestionario corto para verificar la comprensión de los conceptos principales y se realizará un cierre con un resumen de lo aprendido.

## 5. Perfil de la audiencia y estrategia de adaptación del mensaje

### Perfil de la audiencia

La capacitación está dirigida a:

- Estudiantes de diversificado con orientación en computación.
- Estudiantes universitarios de primeros semestres.

En este caso se selecciono estudiantes de diversificado con un nivel de 4to Bachillerato en Computación en un colegio de Zona 1 de la Ciudad de Guatemala con el nombre "Colegio Mixto Indo Latino". 

Se espera que los participantes tengan:

- Uso básico de computadora e Internet.
- Conceptos elementales de programación.
- No se requiere experiencia previa con APIs.

### Estrategia de adaptación del mensaje

Para adaptar el contenido al nivel de la audiencia se utilizarán las siguientes estrategias:

- Explicar primero los conceptos mediante ejemplos cotidianos.
- Utilizar diagramas simples para representar la comunicación entre cliente, API, servidor y base de datos.
- Evitar profundizar en conceptos demasiado avanzados.
- Utilizar ejemplos sencillos de métodos HTTP y respuestas JSON.
- Realizar una actividad práctica para reforzar los conceptos explicados.
- Finalizar con un cuestionario corto para comprobar la comprensión del contenido.
