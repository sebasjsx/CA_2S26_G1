# Requisitos del Negocio

A partir de la entrevista realizada a **Manos Sobre la Pizza** y de las problemáticas identificadas por cada integrante en los elevator pitch, se definieron los siguientes requisitos para la propuesta de solución:

* **RQ-01: Control digital de inventario de insumos**  
  El sistema debe permitir registrar los ingredientes disponibles (queso, embutidos, masa, salsas) y descontar las cantidades automáticamente con cada venta realizada para evitar quedarse sin producto.

* **RQ-02: Gestión y organización de pedidos en horas pico**  
  El sistema debe registrar los pedidos en orden de llegada y mostrar su estado (en espera, en preparación, listo) para agilizar la entrega y evitar confusiones en los turnos de los clientes.

* **RQ-03: Módulo de cotizaciones para eventos y catering**  
  El sistema debe contar con un apartado donde se pueda registrar la fecha del evento, la cantidad de personas solicitadas, calcular el costo estimado y llevar el control de los anticipos pagados.

* **RQ-04: Registro de pedidos con entrega dentro del campus**  
  El sistema debe permitir registrar solicitudes de entrega a diferentes edificios o facultades de la USAC, guardando el lugar de entrega y el contacto del cliente.

* **RQ-05: Catálogo de promociones y combos**  
  El sistema debe mostrar los precios, ofertas especiales y promociones por día para que los clientes puedan consultar las opciones disponibles.

* **RQ-06: Registro diario de ventas y productos más pedidos**  
  El sistema debe guardar el total de ventas del día e indicar qué productos o especialidades de pizza se venden más, ayudando a planificar las compras según la temporada.

### Requisitos Generales

* **RQ-07: Facilidad de uso en mostrador**  
  La interfaz debe ser sencilla y rápida de manejar para que el encargado pueda ingresar datos sin demorar la fila de atención.

* **RQ-08: Acceso desde celular o computadora**  
  El sistema debe funcionar a través de un navegador web para que pueda consultarse tanto en el kiosco como desde el teléfono del encargado.
